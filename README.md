# SolLedger

一个只看**自己**数据的三角洲行动「烽火地带」个人账本：战绩、和好友组队的对局、仓库与资产、出红记录。

取数靠一个浏览器扩展：它在你登录着的 WeGame 三角洲助手页面里查你自己的数据。数据只存在你自己的浏览器里（扩展的 IndexedDB），不经过任何第三方服务器。

> 非官方工具，与腾讯 / WeGame / 三角洲行动官方无关。只读你自己账号能看到的数据，不做任何写操作。官方接口随时可能变化。只支持电脑版 Chrome / Edge。

## v1：当天好友战绩汇总（`v1/`）

选一个日期（默认今天），列出这一天和你同队过的人，汇总每个人的局数、撤离成功、击杀干员、总击杀、助攻、救助、带出价值、盈亏、带出高价值物品和用过的干员；下面还有逐局明细。只汇总，不做分析。

### 安装和使用

1. 在 Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`），打开「开发者模式」，点「加载解压缩的扩展」（Chrome 叫「加载已解压的扩展程序」），选 `v1/dist/ext` 目录。
2. 先在 https://www.wegame.com.cn/helper/df/score/ 用玩三角洲的 QQ 号登录，确认能看到自己的战绩。
3. 点浏览器右上角的「SolLedger · 烽火战绩助手」图标，打开汇总页；选日期，点「同步这一天」。扩展会在后台打开 WeGame 助手页面查数据，查完自动关掉。

### 口径

- 只统计烽火地带，和官方一样不算地图编号 80 的对局；日期按北京时间、按开局时间算。
- 「我」这一行是当天所有对局的合计；其他人是「和我同队的那几局」的合计。同队 2 局以上的人多半是一起组队的好友（官方数据里没有好友标记）。
- 撤离成功（gameResult = 0）、击杀干员（killPlayer）、带出价值、盈亏和官方战绩页口径一致；总击杀、助攻、救助官方烽火界面不显示，仅供参考。
- 干员、地图名称和官方页面一样读腾讯公开的静态配置；读不到时用内置的快照表。

### 隐私和安全

- 扩展只有 `scripting`、`storage` 权限和 www.wegame.com.cn 的站点权限（manifest 写的是助手页面路径，但浏览器按整个站点授权，安装提示也显示整站；扩展只在助手页面里运行取数）；扩展自己不向游戏接口发请求，请求在官方页面里同源发出；不读任何 Cookie 值或登录凭据（只读 `tgp_user_type` 这个 QQ / 微信标记位）。
- 玩家 ID 存之前用本机随机密钥换成代号，原始 ID 不落盘；但密钥和数据在同一个浏览器里，代号只是假名、不是匿名，昵称是明文。数据只在你自己的浏览器里。
- 只有扩展自己的汇总页能让它同步，网页和别的扩展不行。碰到人机校验或登录过期立刻停，不重试。

### 开发

```bash

node v1/test/e2e.mjs                 # 无头 Edge 加载开发版：同步两天、和模拟环境的标准答案逐项对照、人机校验、登录过期
```

## M0 验证工具（`m0/`，已完成）

正式开发之前，先确认官方页面上的数据能不能拿到、长什么样。取数代码在**官方页面里**运行，请求由官方页面自己发出，所以不需要把账号密码交给任何人。

| 验证 | 在哪个页面跑 | 验证什么 |
|---|---|---|
| A · WeGame 助手 | https://www.wegame.com.cn/helper/df/score/ | W1 7 个接口能否调通；W2 单局详情里的队友字段；W3 战绩列表能往前翻多少局 |
| 本机接收页（可选） | http://127.0.0.1:8766/receiver.html | W7 扩展把结果交给我们自己的网页 |

2026-10-27 用真实账号跑过 A：W1~W3 全部通过（一页固定 8 条，按上一页最后一局的时间往前翻，至少能翻 80 局）。

验证 B（官方周报页：大红收藏进度、周报、好友周报）**暂缓**：周报页是手机竖屏页面，电脑上要把窗口调成竖长才能登录。
它的代码在提交 `16a04da` 里（`m0/src/probe-ams.js` 等），要恢复从那里取。

### 会做什么、不会做什么

- 只查烽火地带。最多约 25 次请求（每次间隔 1~1.5 秒，战绩列表的翻页试验放在最后）。
- 报告里只有**结构**：字段名、类型、长度、条数、错误码。没有你的 ID、昵称、战绩数值、场次号；生成报告后还会自检一遍，发现疑似具体值就替换成「[已移除]」。
- 不读、不存、不发任何 Cookie 值、access_token、登录票据。唯一读的 Cookie 是 `tgp_user_type`（QQ / 微信标记位），只用来决定先试哪种账号类型。
- 扩展只有 `scripting`、`storage` 权限和 WeGame 助手页面的路径；扩展自己不发任何网络请求，只有我们自己的网页能和它说话，而且只能读结果、不能发起取数。
- 不伪造请求头。遇到人机校验（错误码 8000022）或未登录 / 登录过期（如 8025004）就立刻停，不重试。
- 结构摘要里，像 ID / 昵称的字段名也只留形态（例如 `<键:digits(18)>`）；错误信息里带数字的长串先换成形态再截断。
- 队友 ID 只以代号的形式交给本机接收页（扩展用本机密钥再哈希一次），不会出现在复制 / 下载的报告里。

### 使用步骤（扩展）

1. 先构建：`node m0/build.mjs`（仓库里已经带了构建好的 `m0/dist/ext/`，没改代码可以跳过）。
2. 在 Chrome 打开 `chrome://extensions`（Edge 打开 `edge://extensions`），打开「开发者模式」，点「加载解压缩的扩展」，选 `m0/dist/ext` 目录。
3. 点浏览器右上角的扩展图标，打开「SolLedger 数据助手」，点「跑验证 A」。扩展会打开 WeGame 助手页面：没登录的话先用 QQ 号登录，再点一次。面板显示「完成」后，在扩展弹窗里点「复制报告」。
   生涯页只显示「无角色信息」、或者扩展说「登录已过期」时：到 www.wegame.com.cn 右上角退出，用 QQ 重新登录。
4. （可选）运行 `node m0/serve.mjs`，在扩展弹窗里点「打开本机接收页」，接收页会自动从扩展读到报告（W7）。看完点「清空本页数据」。

备用：不想装扩展的话，用 Chrome / Edge 打开 `m0/dist/install.html`，把书签拖到书签栏，在 WeGame 助手页面上点。取数代码和扩展是同一份。

## 开发

需要 Node.js 22 或更新版本，没有其他依赖。

```bash
node m0/build.mjs                       # 生成书签、扩展正式版 dist/ext、开发版 dist/ext-dev、安装页
node --test m0/test/common.test.mjs     # 单元测试 + 源码红线扫描 + 扩展正式版权限检查
```

端到端测试在本地模拟环境里跑完整流程：

```bash
node m0/mock/server.mjs     # 模拟官方页面与接口，127.0.0.1:8770
node m0/serve.mjs           # 本机接收页，127.0.0.1:8766
node m0/test/e2e-ext.mjs    # 无头 Edge 加载开发版扩展：A → 接收页读取（W7）→ 网站只能读 → 各种「立刻停」场景
node m0/test/e2e-cdp.mjs    # 书签：A → 交接（W7）→ 各种「立刻停」场景（Edge 或 Chrome）
```

`e2e-ext.mjs` 只能用 Edge：Chrome 正式版已经不支持用命令行参数加载解压缩的扩展。开发版扩展 `dist/ext-dev` 多了本地模拟环境的权限，只给自动化测试用，不进仓库。

模拟页地址可以带参数造异常情况（见 `m0/mock/server.mjs` 开头）：`?captcha=1`、`?captcha=paging`、`?role8000102=1`、`?expired=1`。

目录：

```
m0/
  src/common.js         共用：结构摘要、自检、面板、交接
  src/probe-wegame.js   取数脚本 A
  ext/                  扩展源码：后台、弹窗、网站桥接（site-bridge）
  receiver.html         本机接收页
  build.mjs             打包成书签、扩展、安装页
  serve.mjs             本机接收页的静态服务（只监听 127.0.0.1）
  mock/server.mjs       本地模拟环境（只用于测试）
  test/                 单元测试与端到端测试
  dist/                 构建产物（扩展正式版、书签源码、安装页）
```
