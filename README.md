# SolLedger

一个只看**自己**数据的三角洲行动「烽火地带」个人账本（网页版，规划中）：战绩、和好友组队的对局分析、仓库与资产、出红记录。

数据只存在你自己的浏览器里（IndexedDB），网站本身是纯静态页面（GitHub Pages），不经过任何第三方服务器。

> 非官方工具，与腾讯 / WeGame / 三角洲行动官方无关。只读你自己账号能看到的数据，不做任何写操作。官方接口随时可能变化。

## 现在有什么：M0 验证书签

正式开发之前，先用两个「书签脚本」确认官方页面上的数据能不能拿到、长什么样。
书签在**官方页面里**运行，请求由官方页面自己发出，所以不需要你把账号密码交给任何人。

| 书签 | 在哪个页面点 | 验证什么 |
|---|---|---|
| M0-A WeGame | https://www.wegame.com.cn/helper/df/score/ | W1 7 个接口能否调通；W2 单局详情里的队友字段；W3 战绩列表能往前翻多少局 |
| M0-B 周报页 | https://df.qq.com/cp/weekly20250821/index.html | W4 能否借用页面自带的请求函数；W5 周报、好友周报、个人资产、大红收藏能否取到 |
| 本机接收页（可选） | http://127.0.0.1:8766/receiver.html | W6 好友 ID 与对局队友 ID 是不是同一套；W7 书签把结果交给我们自己的网页 |

### 书签会做什么、不会做什么

- 只查烽火地带。A 最多约 25 次请求（每次间隔 1~1.5 秒，战绩列表的翻页试验放在最后），B 大约 7 次（每次间隔约 1 秒）。
- 报告里只有**结构**：字段名、类型、长度、条数、错误码。没有你的 ID、昵称、战绩数值、场次号；生成报告后还会自检一遍，发现疑似具体值就替换成「[已移除]」。
- 不读、不存、不发任何 Cookie 值、access_token、登录票据。唯一读的 Cookie 是 `tgp_user_type`（QQ / 微信标记位），只用来决定先试哪种账号类型。
- 不伪造请求头。遇到人机校验（错误码 8000022）、未登录，或官方请求 15 秒没有回应（多半是弹了验证码 / 登录框）就立刻停，不重试。
- 结构摘要里，像 ID / 昵称的字段名也只留形态（例如 `<键:digits(18)>`）；错误信息里带数字的长串先换成形态再截断。
- W6 需要比较 ID 时，只在本机接收页里比较哈希（SHA-256 前 12 位），哈希不会出现在复制 / 下载的报告里。

### 使用步骤

1. 用 Chrome 或 Edge 打开 `m0/dist/install.html`，按 `Ctrl+Shift+B` 显示书签栏，把页面上两个蓝色按钮**拖**到书签栏。
2. 打开 WeGame 助手页面，用 QQ 号登录，确认能看到自己的烽火战绩，然后点书签 **M0-A WeGame**。面板显示「完成」后点「复制报告」。
3. 打开官方周报页，用同一个 QQ 号登录，点书签 **M0-B 周报页**，同样复制报告。
4. （可选）运行 `node m0/serve.mjs`，再分别在两个面板里点「测试交接（W7）」，接收页会显示 W6 / W7 的结果。

## 开发

需要 Node.js 22 或更新版本，没有其他依赖。

```bash
node m0/build.mjs                       # 生成 dist/bookmarklet-A.js、bookmarklet-B.js、install.html
node --test m0/test/common.test.mjs     # 单元测试 + 源码红线扫描（不许出现读凭据的写法）
```

端到端测试在本地模拟环境里跑完整流程（需要本机装有 Edge 或 Chrome）：

```bash
node m0/mock/server.mjs     # 模拟官方页面与接口，127.0.0.1:8770
node m0/serve.mjs           # 本机接收页，127.0.0.1:8766
node m0/test/e2e-cdp.mjs    # 无头浏览器跑 A → 交接 → B → 交接 → W6 比对，再跑各种「立刻停」场景
```

模拟页地址可以带参数造异常情况（见 `m0/mock/server.mjs` 开头）：`?captcha=1`、`?captcha=paging`、`?role8000102=1`（WeGame 页），`?stall=2`、`?noOapI101=1`（周报页）。

目录：

```
m0/
  src/common.js         共用：结构摘要、自检、面板、交接
  src/probe-wegame.js   书签 A
  src/probe-ams.js      书签 B
  receiver.html         本机接收页
  build.mjs             打包成书签与安装页
  serve.mjs             本机接收页的静态服务（只监听 127.0.0.1）
  mock/server.mjs       本地模拟环境（只用于测试）
  test/                 单元测试与端到端测试
  dist/                 构建产物（书签源码、安装页）
```
